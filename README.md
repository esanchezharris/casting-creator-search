# Casting: natural-language creator search

Type who a campaign needs in plain English. The query is split into editable
filters (niche, place, follower range, engagement) plus a topic that is ranked
against each creator's recent posts. Sweep the pointer across a photo to flip
through a profile without opening it.

All creators are fictional and generated by `scripts/seed.py`.

## Run it

    npm install
    npm run dev          # http://localhost:3000

No API key is needed. Without one the app uses the rule-based parser and
keyword ranking.

## Turn on the language-model parts

    cp .env.example .env.local     # add OPENAI_API_KEY
    OPENAI_API_KEY=... npm run embed   # writes data/embeddings.json
    npm run dev

With a key set, queries are parsed by the LLM (falling back to rules on any
error), and once `data/embeddings.json` exists results are ranked by meaning:
each post is embedded separately, so "caffeine before the gym" can find a
pre-workout post and quote it as the reason.

## Measure it

    npm run eval         # app must be running

Prints, per test query, whether the filters were parsed correctly and the
precision of the top five results. Baseline with no key (rules + keywords):
13/15 filters correct, mean P@5 0.91. The two parser misses are the same
mistake: a topic word ("running shoes", "the gym") read as a creator type.
To compare modes with a key set, restart the app with `PARSER=rules` or
`RANKER=keywords`.

The eval is small and the captions are templated, so treat the numbers as a
regression check, not proof of quality. Add harder queries as you find them.

## Real photos

    PEXELS_API_KEY=... python3 scripts/fetch_images.py

Swaps the placeholder photos for Pexels portraits grouped by photographer.
This script has not been run against the live API yet.

## Layout

    scripts/seed.py            dataset generator
    scripts/embed.py           embeddings for profiles and posts
    scripts/eval.py            parser + ranking eval
    src/lib/parse.ts           rule parser, LLM parser, output validation
    src/lib/search.ts          filters, keyword ranking, embedding ranking
    src/app/api/search         POST { query } or { filters }
    src/components/CreatorCard.tsx   scrub preview
    src/app/globals.css        design tokens at the top

## Deploy

Push to GitHub and import into Vercel. Commit `data/embeddings.json` and set
`OPENAI_API_KEY` in the project's environment variables.
